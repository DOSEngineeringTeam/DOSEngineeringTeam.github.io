# DOS Engineering Team

Сайт-визитка компании. Внешний вид и функции сохранены из исходного HTML.

## Публикация на GitHub Pages

1. Загрузите index.html, .nojekyll и README.md в корень репозитория.
2. Откройте Settings → Pages.
3. В Source выберите Deploy from a branch.
4. Выберите main и /(root), нажмите Save.
5. Дождитесь завершения публикации. Ссылка появится в Settings → Pages.

Для бесплатного GitHub Pages выберите публичный репозиторий.
Не загружайте ZIP целиком: сначала распакуйте его.

## Возможности

- Адаптивная вёрстка и мобильное меню.
- Семь языков: русский, английский, немецкий, китайский, японский, корейский, хинди.
- Выбор языка по настройкам браузера, ручное переключение и сохранение выбора.
- Кнопки перехода в Telegram: https://t.me/DOSRequestHub_bot
- Разделы экспертизы, проектов, процесса и контактов.

Логотип встроен в HTML. Шрифты загружаются из Google Fonts.
Сборка, Node.js, сервер приложений и платный хостинг не требуются.
